# 買い時チェッカー Ver.5.1 — 自動商品検索連携版

## 今回の変更
- 商品バーコードをカメラに映すだけで自動認識
- 読み取り成功時にチェックマークの成功エフェクトを表示
- 成功エフェクト後、**「このバーコードで商品を確認」を押さなくても自動で商品確認画面へ移動**
- まずアプリ内の商品マスターを検索
- 未登録の場合は Open Food Facts の商品データも自動検索
- 商品名・メーカー・容量・商品画像が取得できれば自動で商品マスターへ登録
- 外部DBにない商品は、そのまま「この商品を登録する」画面へ進める
- 「このバーコードで商品を確認」ボタンは手動確認用の予備導線として残しています

## iPhoneでの流れ
1. 「商品バーコードをスキャン」
2. バーコードをカメラに映す
3. 自動認識 → 成功エフェクト
4. 自動で商品検索
5. 登録済みなら商品情報・買い時判定を表示
6. 未登録でも外部DBにあれば商品情報を自動取得
7. 見つからなければ商品登録画面へ

GitHub Pagesへ上書きした後、iPhone Safariでページを再読み込みしてください。
ホーム画面に追加済みの場合、古いキャッシュが残ることがあるため、まずSafariでURLを直接開いて確認するのがおすすめです。
