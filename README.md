# 買い時チェッカー Ver.5（Windows開発・iPhone実機テスト版）

## 目的
Mac/Xcodeなしで、Windows PCから開発し、iPhoneのSafariで実際に使える最初の試作版です。

## 主な機能
- JANコードをiPhoneカメラでスキャン
- JANコード手入力
- 商品マスター登録
- 商品名・メーカー・容量
- iPhoneカメラで商品写真を撮影して保存
- 店舗を現在地から検索（OpenStreetMap/Overpass利用）
- 店舗名の手入力
- 価格・日付を保存
- 過去価格の平均・最安・最高を表示
- 現在価格が平均より10%以上安い場合「かなり買いやすい価格」
- 平均より10%以上高い場合「過去平均より高め」
- ホーム画面に追加できるPWA
- データは現在、端末内のlocalStorageに保存

## Windowsで動かす
1. このフォルダをWindows PCにコピー。
2. VS Codeなどで開く。
3. HTTPSで公開する必要があります。最も簡単なのはGitHub Pagesです。
4. GitHub Pagesで公開したURLをiPhoneのSafariで開きます。
5. Safariの「共有」→「ホーム画面に追加」でアプリのように使えます。

## 注意
カメラ・位置情報はHTTPSのページで利用するのが基本です。
GitHub PagesなどHTTPSの環境でテストしてください。
