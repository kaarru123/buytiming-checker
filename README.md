# 買い時チェッカー Ver.5.1 — 商品バーコード連続スキャン強化版

- カメラは1回だけ取得し、同じ映像を解析
- 120ms間隔で連続スキャン（約8回/秒）
- 中央82%×48%の読み取り領域を優先し、4回に1回は全画面も解析
- EAN-13 / EAN-8 / UPC-A / UPC-E を対象
- 同じバーコードを2回検出してから確定（1.8秒以内）
- 誤検出を減らすため、読み取り成功エフェクト＋軽い振動＋番号表示
- 写真撮影は不要
- iPhone Safari向けに `TRY_HARDER` は使用しない構成

GitHub Pagesで公開後、Safariで再読み込みしてください。ホーム画面追加済みの場合は、まずSafariのURLを直接開いて動作確認することを推奨します。
