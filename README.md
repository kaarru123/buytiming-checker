# 買い時チェッカー Ver.5.1

WindowsでGitHub Pagesに公開し、iPhone Safariから利用するPWA型プロトタイプです。

## Ver.5.1の主な変更
- 買い物リストを無料版の主要機能として最初から搭載
- JAN商品のスキャン・手入力・商品登録・価格履歴
- JANなし商品：よく使う商品 → カテゴリ → 肉の部位などを選択 → その他を追加
- 肉・魚は100g単価、野菜などは個数単価、重量商品はkg単価に正規化して比較
- 使うほどJANなし商品の「よく使う商品」に上がる
- 店舗選択、現在地検索、手入力
- iPhoneの安全領域を考慮し、画面上部に寄りすぎないレイアウト
- JANスキャン押下でカメラを起動。Safariの許可不足時は案内モーダルを表示

## データ設計
localStorageに以下を保存します。
- products: JAN商品マスター
- customProducts: JANなし商品マスター
- records: 価格履歴（raw price + normalized unitPrice）
- shoppingList: 買い物リスト

この構造は将来、購入履歴・家計管理・クラウド同期・家族共有などを追加できるように拡張しやすくしています。

## iPhoneでカメラが使えない場合
Safariのサイト設定でカメラを「許可」に変更してください。WebアプリからiOS設定アプリの特定画面を自動で開くことはできません。GitHub PagesのHTTPS上で利用してください。
